## 不可直接推定
- 馬達／舵機控制 Topic、訊息型別、單位、上下限及原廠啟動指令。
- 雷射雷達品牌型號、相機驅動與各感測器 Topic。
- 四個馬達介面表示本車為四輪獨立驅動。規格列出馬達 ×2，需以實物及原廠資料確認。
- 短路／過流保護可替代急停。

核對每一項實作請填 `r2-interface-inventory.md`，並記下手冊或官方套件來源與版本。
