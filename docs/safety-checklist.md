# 實機操作安全檢查表

本表是教學輔助，不取代原廠手冊。若原廠要求更嚴格，依原廠規定。

## 上電前
- [ ] 已閱讀該套裝版本的原廠操作與充電說明。
- [ ] 電池、線材、插頭與車體無破損、異味、異常發熱或膨脹；有異常即停止使用。
- [ ] 車輪架空或車體置於穩固支架，或已清空並隔離低速測試區。
- [ ] 操作者知道原廠正常停止方法及可立即切斷供電的位置。
- [ ] 遙控器／控制程式已設定低速；測試區內無人、寵物與易損物。
- [ ] 桌面與車體固定，線材不會捲入車輪或舵機。

## 測試中
- [ ] 先確認感測與狀態資料，再發送任何移動命令。
- [ ] 低速、短距離、單一動作測試；每次只改一個變因。
- [ ] 手把或網路失聯時，立即依原廠方式停止／斷電。
- [ ] 出現方向錯誤、非預期加速、異音、過熱或控制失效，立即停止，不反覆嘗試。

## 收尾
- [ ] 已停止所有移動命令並確認車體靜止。
- [ ] 依原廠流程關閉系統與電源；不帶電插拔未經確認的介面。
- [ ] 記錄問題、版本與重現步驟；分享資料前移除密碼、Wi-Fi 金鑰及個資。

注意：短路／過流保護不等同於可由操作者觸發的急停，也不能保證所有失控情境安全。
